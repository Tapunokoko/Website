Singing Stepper Motor

Engr 346 · Iron Range Engineering · Sept to Oct 2026

Abstract

I made a stepper motor play music. Each step makes a click, and the number of steps per second is the pitch. I drove a 28BYJ-48 motor with an Arduino Uno and a ULN2003 driver, tested three drive modes, and measured the pitch and the top speed. The motor stopped turning at 650 steps/s in wave mode, 700 in full step, and 1400 in half step. Below the stall limits, the measured pitch matched the commanded pitch.

My goals
  1. Explain why a stepper motor makes a musical note.
  2. Check if the real pitch matches the pitch the code asks for.
  3. Compare three drive modes: wave, full step, and half step.
  4. Find the top speed before the motor stops turning (stalls).
Three class topics behind it
Magnetic circuits
ℱ = N·I  ·  Φ = ℱ / ℛ

More current makes more flux and a stronger pull, which is why two coils (full step) pull harder than one (wave).

Faraday's and Lenz's laws
V = I·R + e

The spinning rotor makes a back EMF that fights the supply. The faster it spins, the less current flows, until the motor stalls.

Synchronous motors
ns = 120·fe / P

The rotor follows a stepping magnetic field. A stall is like a synchronous motor falling out of step.

Half step stalled at exactly twice the full step rate, so both hit the same shaft speed, about 20.5 rpm with the ramp off and 31 to 32 rpm with it on. The limit depends on how fast the rotor spins, which points to back EMF. With the ramp on, full step went 57% faster, half step 50%, and wave 8%.

Wave and full step lost the note at 659 Hz and up, right at their stall limits, where the rotor slips and the clicks stop being even. Half step kept turning up to 1400, but it switches between 1 and 2 coils, so every other click is weaker and the app could not find one clear pitch above 392 Hz.

The 50 Ω rating is for a whole coil: orange to pink measured 46 Ω, which is 2 × 23. Full step draws about 440 mA, close to the 500 mA a USB port gives, so the supply sagged from 4.9 V to 4.6 V while running.

Where this matters
  • Quieter machines. 3D printers are loud because of these step clicks. Drivers that use smaller steps (microsteps) are quieter.
  • Not skipping steps. Most stepper systems have no position sensor, so staying below the stall limit and using a ramp keeps the motor on track.
  • Picking a mode. Full step for the most pull, wave for the least power, half step for smoother movement.

singing_stepper.ino · Arduino · 196 lines View on GitHub 
/*
  Singing Stepper - Engr 346 DLA

    Type a command and press Enter:
    440     play 440 steps/s (= 440 Hz) until the next command
    w f h   wave / full / half step mode
    r       ramp on/off (start at 100 steps/s and speed up)
    t       test: play 10 notes, 3 s each, 1 s quiet between
    p       play the Alphabet song ( Just for fun)
    + -     song one octave up / down
    s       stop
  Typing anything while the motor is playing stops it.
*/

// Counts how many items are in a list. Example: COUNT(ALPHABET) = 42
#define COUNT(list) (sizeof(list) / sizeof(list[0]))

const int PIN[4] = {8, 9, 10, 11};   // IN1, IN2, IN3, IN4

// Coil table: 1 = coil on. Columns are IN1, IN2, IN3, IN4.
// Even rows have 1 coil on (wave drive). Odd rows have 2 coils on (full step).
// Half step uses every row, so it switches between 1 and 2 coils.
const byte COILS[8][4] = {
  {1, 0, 0, 0},   // row 0
  {1, 1, 0, 0},   // row 1
  {0, 1, 0, 0},   // row 2
  {0, 1, 1, 0},   // row 3
  {0, 0, 1, 0},   // row 4
  {0, 0, 1, 1},   // row 5
  {0, 0, 0, 1},   // row 6
  {1, 0, 0, 1}    // row 7
};

// =================== INPUTS: change these, not the functions ===================

// Test notes in steps/s (= Hz)
const float TEST_NOTES[] = {262, 294, 330, 349, 392, 440, 523, 659, 784, 880};

// Note frequencies in Hz. Add more here if a new song needs them.
const float NOTE_C4 = 261.63, NOTE_D4 = 293.66, NOTE_E4 = 329.63;
const float NOTE_F4 = 349.23, NOTE_G4 = 392.00, NOTE_A4 = 440.00;

// A song is a list of {note, length} pairs.
// Length: 2 = eighth, 4 = quarter, 8 = half note
const float ALPHABET[][2] = {
  {NOTE_C4, 4}, {NOTE_C4, 4}, {NOTE_G4, 4}, {NOTE_G4, 4}, {NOTE_A4, 4}, {NOTE_A4, 4}, {NOTE_G4, 8},  // A B C D E F G
  {NOTE_F4, 4}, {NOTE_F4, 4}, {NOTE_E4, 4}, {NOTE_E4, 4},                                            // H I J K
  {NOTE_D4, 2}, {NOTE_D4, 2}, {NOTE_D4, 2}, {NOTE_D4, 2}, {NOTE_C4, 8},                              // L M N O P
  {NOTE_G4, 4}, {NOTE_G4, 4}, {NOTE_F4, 8}, {NOTE_E4, 4}, {NOTE_E4, 4}, {NOTE_D4, 8},                // Q R S, T U V
  {NOTE_G4, 4}, {NOTE_G4, 4}, {NOTE_F4, 8}, {NOTE_E4, 4}, {NOTE_E4, 4}, {NOTE_D4, 8},                // W X, Y and Z
  {NOTE_C4, 4}, {NOTE_C4, 4}, {NOTE_G4, 4}, {NOTE_G4, 4}, {NOTE_A4, 4}, {NOTE_A4, 4}, {NOTE_G4, 8},  // Now I know my A B C's
  {NOTE_F4, 4}, {NOTE_F4, 4}, {NOTE_E4, 4}, {NOTE_E4, 4}, {NOTE_D4, 4}, {NOTE_D4, 4}, {NOTE_C4, 8}   // Next time won't you sing with me
};

// ===============================================================================

const int GAP_MS = 30;  // short silence after each note

byte row = 1;        // current row of the coil table
byte stepSize = 2;   // 2 for wave or full (skip every other row), 1 for half
char mode = 'f';
bool rampOn = false;
float octave = 1.0;  // 1 = as written, 0.5 = one octave down, 2 = one octave up

// Turn the coils on/off to match one row of the table
void setCoils(byte r) {
  for (int i = 0; i < 4; i++) digitalWrite(PIN[i], COILS[r][i]);
}

void allOff() {
  for (int i = 0; i < 4; i++) digitalWrite(PIN[i], LOW);
}

// One click of the motor: move to the next row
void oneStep() {
  row = (row + stepSize) % 8;
  setCoils(row);
}

void setMode(char m) {
  mode = m;
  if (m == 'w') { row = 0; stepSize = 2; }   // even rows only
  if (m == 'f') { row = 1; stepSize = 2; }   // odd rows only
  if (m == 'h') { stepSize = 1; }            // every row
  Serial.print("Mode: ");
  Serial.println(m);
}

// Print the tone info before playing
void printInfo(float hz) {
  unsigned long period = 1000000.0 / hz;          // microseconds between steps
  float stepsPerRev = (stepSize == 1) ? 4096 : 2048;
  Serial.print("Mode ");          Serial.print(mode);
  Serial.print(" | commanded ");  Serial.print(hz);
  Serial.print(" | timed ");      Serial.print(1000000.0 / period);
  Serial.print(" | shaft RPM ");  Serial.println(hz * 60 / stepsPerRev);
  Serial.flush();                 // finish printing before the motor starts
}

// Step at 'hz' steps per second for 'ms' milliseconds.
// ms = 0: keep going until new input arrives.
// Returns false if stopped by new input.
bool playTone(float hz, unsigned long ms) {
  float rate = hz;
  if (rampOn && hz > 100) rate = 100;           // ramp: start slow
  unsigned long period = 1000000.0 / rate;      // microseconds between steps
  unsigned long start = millis();
  unsigned long lastStep = micros();
  setCoils(row);

  while (ms == 0 || millis() - start < ms) {
    if (Serial.available()) {                   // new input: stop
      allOff();
      return false;
    }
    if (micros() - lastStep >= period) {        // time for the next step?
      lastStep += period;                       // keeps the steps evenly spaced
      oneStep();
      if (rate < hz) {                          // ramp: speed up a little each step
        rate = min(rate + 2000.0 / rate, hz);
        period = 1000000.0 / rate;
      }
    }
  }
  allOff();
  return true;
}

// Play each note in a list, with quiet between.
// Inputs: the list of notes, how many notes, on time (ms), off time (ms).
void runTest(const float notes[], int count, unsigned long onMs, unsigned long offMs) {
  Serial.println("Test start");
  for (int i = 0; i < count; i++) {
    Serial.print("[");
    Serial.print(i + 1);
    Serial.print("] ");
    printInfo(notes[i]);
    if (!playTone(notes[i], onMs)) return;     // stopped early
    delay(offMs);
  }
  Serial.println("Test done");
}

// Play a song.
// Inputs: the song (list of {note, length} pairs), how many notes, and the tempo (BPM).
// Length units: 1 = sixteenth, 2 = eighth, 4 = quarter, 8 = half note.
void playSong(const float song[][2], int count, int bpm) {
  unsigned long sixteenthMs = 15000UL / bpm;   // 60000 ms per minute / bpm / 4
  Serial.println("Song starts in 2 s...");
  delay(2000);                                 // time to start recording
  for (int i = 0; i < count; i++) {
    float hz = song[i][0] * octave;                              // column 0 = the note
    unsigned long noteMs = song[i][1] * sixteenthMs - GAP_MS;    // column 1 = the length
    Serial.println(hz);
    Serial.flush();
    if (!playTone(hz, noteMs)) return;         // play the note (stop on new input)
    delay(GAP_MS);
  }
  Serial.println("Song done");
}

void setup() {
  for (int i = 0; i < 4; i++) pinMode(PIN[i], OUTPUT);   // pins start LOW, so all coils start off
  Serial.begin(9600);
  Serial.println("Singing Stepper ready");
  Serial.println("Commands: number, w f h, r, t, p, + -, s");
}

void loop() {
  if (!Serial.available()) return;             // nothing typed yet

  String cmd = Serial.readStringUntil('\n');   // read the typed command
  cmd.trim();                                  // remove spaces and the Enter key
  if (cmd.length() == 0) return;
  char c = cmd[0];

  if (c == 'w' || c == 'f' || c == 'h') setMode(c);
  else if (c == 'r') {
    rampOn = !rampOn;
    Serial.println(rampOn ? "Ramp ON" : "Ramp OFF");
  }
  else if (c == 't') runTest(TEST_NOTES, COUNT(TEST_NOTES), 3000, 1000);   // notes, count, 3 s on, 1 s off
  else if (c == 'p') playSong(ALPHABET, COUNT(ALPHABET), 100);             // song, count, 100 BPM
  else if (c == '+') { octave = octave * 2; Serial.print("Octave x"); Serial.println(octave); }
  else if (c == '-') { octave = octave / 2; Serial.print("Octave x"); Serial.println(octave); }
  else if (c == 's') Serial.println("Stopped");
  else {
    float hz = cmd.toFloat();                  // turn text like "440" into a number
    if (hz >= 1 && hz <= 3000) {
      printInfo(hz);
      playTone(hz, 0);                         // play until the next input
    } else {
      Serial.println("Unknown command");
    }
  }
}

Lamppa Sauna

Client project · Lamppa Manufacturing · 4-person student team · Fall 2026
In progress · 4 of 8 tests done

Lamppa Manufacturing built an electric sauna stove and wanted to know how it heats their sauna trailer and how evenly the heat spreads. I lead the technical work on our 4-person student team: I set the layout of 12 thermocouples across three data loggers, so every reading is logged automatically once a minute instead of written by hand, and I set up the statistics we use to analyze the data.

12sensors logged every minute, up from Lamppa's 8 written by hand
12–35°Clower bench cooler than head level once the room is hot
~2minextra heat-up time from each door entry
0.06°C/minat most, the spread in heating rate between repeated tests
Scope

We started out planning an airflow study, but after meeting Lamppa's owner and lead engineer, we learned the stove is close to UL 875 approval and what they need is trustworthy temperature data, so we rebuilt the problem, objectives, and test plan around temperature.

Layout

I placed the 12 sensors where people sit and where heat enters and leaves, four on each of three data loggers, so each logger covers one zone of the room.

Statistics

I set up the mean and standard deviation (how even the room is, and how closely tests repeat) and the heating rate (the slope of a line through the first 20 minutes). A linear regression of heat-up time against outdoor temperature comes next, once the vents-open tests run on colder and warmer days.

Door

Each door entry drops the stove area and mid bench by about 10 °C but head level only 1 to 6 °C, and every sensor recovers in about 2 to 4 minutes. A hotter room loses more per entry (R² = 0.84).

Floor

The floor, not the stove inlet, is the coldest spot, and it gets worse on cold days and with door openings.

The stove heats the room with the same uneven pattern every time, hot at head level and cool down low, which gives Lamppa a temperature map they can predict.Key finding so far
What comes next

Four tests are left: three with the vents open on colder and warmer days, and one with a towel at the door to see if it heats the room faster. I also wrote the heat transfer and ventilation reference for the next team (energy balance, stack effect, and a heat-up time model), and I will set up a draft SolidWorks model of the hot room for them to run Flow Simulation on.
